# 对标复原

对标复原有两步：先把对标片子自己的结构原样梳理出来，再归因：它凭什么拿到这个数据。产出是一张复原卡（[模板](../templates/复原卡.md)）。在选题验证里，复原卡的主要用途是给评论触发表提供镜次和原句。

## 一、前提

1. **先有逐字稿。** 凭标题、封面、评论区推测的内容一律不算数。
2. **先复原，后归因。** 顺序不能颠倒。复原写完之前，不写「它为什么火」。
3. **只用对标自己的材料**：逐字稿、秒数、画面、字幕、评论。

## 二、复原：原样梳理它的结构

### 切段与命名

1. **按片子自己的转折切段。** 有几段就是几段，不凑数。不按任何现成模板的格子去切。
2. **段名用片中的原话**，例如：`报三条 → 今天一条都没有 → 现场点名`。
3. **再给每段标手法**，用短视频通用词说明这一段在做什么（见下表）。一段可以有多个手法，也可以没有。
4. **不硬套模板。** 先切段、命名，再标手法。不为凑齐某个模板而增减段落，也不把模板里有、片子里没有的手法写进去。模板套不上的地方，往往是这条片子独有的做法，要原样写出来。

| 手法 | 含义 |
|---|---|
| 钩子 | 开头让观众决定留下来的内容：一个问题、一个反常画面、一句狠话 |
| 铺垫 | 给后面的矛盾或反转准备信息 |
| 矛盾 | 人物之间、人物和处境之间的对立 |
| 加码 | 矛盾升级，压力变大 |
| 预期违背 | 观众以为会这样，结果不是 |
| 反转 | 局面或立场翻过来 |
| 悬念 | 先抛问题，晚一点才给答案 |
| 爽点 | 憋屈的一方扳回来，观众觉得解气 |
| 落点 | 结尾停在哪一句、哪一个画面 |

不够用时可以加词。新词第一次出现时，写一句含义。

### 复原卡的内容

| 部分 | 写什么 |
|---|---|
| 身份与读数 | 链接、作者、发布时间、抓取时间、距发布小时、赞评转藏、比率算式、时长、逐字稿来源 |
| 台词表 | 镜／时间／说话人／台词，一行一个说话人 |
| 框架线 | 每段：秒区间、原话命名、手法、观众新得到什么、观众反应（笑、记、骂、转、答） |
| 关键帧记录 | 只取开头 3 秒、结尾、转折点。先切段定转折点，再运行 `scripts/frames.py <视频或保存目录> --at <转折秒数…>` 截帧；逐张看图，写时间点、人物和场景、字幕、与台词的关系。没看的写「未读」，不编 |
| 读数与评论 | 评论样本口径、评论触发表（见 [评论机制](评论机制.md) 第四节）。**评论归因只写在这里** |
| 归因 | 完播、赞、转、藏四项，见第三节 |

## 三、归因：它凭什么拿到这个数据

三条要求：

1. 每条归因指到框架线的段号。
2. 每条写清段号、秒数和手法。指不到的写「未归因」。
3. 允许写「不知道」。归因都是假设，不能当因果结论用。

评论归因不在这张表里写，只写在评论触发表（复原卡「读数与评论」一节）。两张表分工：

| 表 | 管什么 | 改编时怎么用 |
|---|---|---|
| 评论触发表 | 评论：每个大簇由哪一镜、哪一句、通过哪一格机制触发 | 逐行定保留、强化、放弃或新增，决定要激活哪几格、从哪一镜触发 |
| 归因表 | 完播、赞、转、藏：哪几段在服务这四项 | 判断哪些段落和手法不能动，哪些可以换 |

| 维度 | 能拿到什么 | 归因写什么 |
|---|---|---|
| 完播 | 对标的完播率看不到。从片子本身推断，见下文 | 哪几段让观众留下来、用了什么手法 |
| 赞 | 赞数、TOP 评论赞 ÷ 视频赞 | 哪一段让观众想替它下判词 |
| 转 | 转 ÷ 赞 | 有没有能转给某个具体的人的东西 |
| 藏 | 藏 ÷ 赞 | 有没有能抄走的东西（做法、话术、清单） |

### 完播怎么归因

对标的后台完播率看不到，所以完播归因都是推断。从框架线逐段看下面几项，写出它做得好的点，每一点指到段号和秒数：

1. **开头**：钩子在第几秒出现，是什么；观众在前 3 秒得到什么。
2. **观众反应**：每段结束时，观众有没有一个理由继续看（一个没回答的问题、一个升级的矛盾、一个等着看结果的局面）。
3. **信息密度**：均速多少字／秒；每段观众新得到什么；有没有没有新信息的段落。
4. **叙事手段**：预期违背、反转、悬念、加码在哪几段，间隔多少秒。
5. **结尾**：落点在哪；结尾是否让人想回看或想评论。
6. **辅助证据**：时长档，评论里「看到最后」「看了两遍」一类原句，转发量级。

最后写一句：**这个结构好在哪**，指到段号。

## 四、证据等级（用于评论触发表）

| 等级 | 含义 |
|---|---|
| 🟢 | 直接看到：逐字稿原句、评论原句、页面读数 |
| 🟡 | 由相邻证据推断 |
| 🔴 | 只是读者的读法，或没有直接证据 |

读数、逐字稿、抓取时间三样齐全，复原卡才算完成。缺的写「未采」，不估。
