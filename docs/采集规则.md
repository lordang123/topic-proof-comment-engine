# 采集规则

## 一、原则

1. **只读你自己登录后、页面上能看到的内容。** 不调用、不逆向平台接口。
2. **低频、串行。** 同一时间只打开一个抖音页面。访问间隔随机，不缩短。
3. **采集不做判断。** 判断只在两处做：搜索前（定搜索词、判同题）和采集后（分析）。
4. **不存个人信息。** 不保存评论者昵称、头像、IP 属地。
5. **视频首选你自己已有的文件。** 没有文件时，可选用「保存当前视频用于学习研究」：只保存对标这一条，不保存同题片；只保存你有权观看的内容；取音轨和画面，截完关键帧后默认删除，只留逐字稿和关键帧图除。保存的文件不转发、不公开、不用于再创作素材。

## 二、分工

| 阶段 | 谁做 | 要求 |
|---|---|---|
| 1 定搜索词、判同题 | 分析员 | 要判断 |
| 2 采集 | 采集员（只跑脚本） | 不判断，只执行 |
| 3 分析 | 分析员 | 要判断 |

## 三、访问节奏

| 项 | 默认值 |
|---|---|
| 视频页间隔 | 85% 的情况取 8–15 秒随机，15% 取 20–40 秒随机 |
| 抓过评论的页 | 已用的滚动时间从间隔里扣掉，至少再等 3–6 秒 |
| 搜索词间隔 | 70% 的情况取 12–30 秒随机，30% 取 30–60 秒随机 |
| 每条片子的搜索词 | ≤6 个 |
| 搜索结果 | 只取「视频」标签首屏，不滚动翻页 |
| 等评论数出现 | 每秒查一次，最多 15 秒 |
| 并行 | 不并行。同一登录状态下，抖音页面一次只开一个 |


### 减少访问次数

1. **一次读完**：每个候选视频页只打开一次，读数和评论在同一次访问里取完。
2. **预筛**：推荐卡片上点赞 <1500 的不访问（评论数 >500 的片子，点赞一般远高于这个数）。阈值可调。
3. **缓存**：已经抓过评论、或近期确认评论 ≤500 的片子，不重读。

## 四、评论抽样

| 项 | 默认值 |
|---|---|
| 顶层评论加载上限 | 200 条 |
| 抽样 | 90 条：赞最高 45 条 ＋ 按加载顺序等距取 45 条 |
| 回复 | 只展开赞最高的前 3 条评论的回复，标「楼中回复」 |
| 作者评论 | 标出，分析时去掉 |

- 结论里写明「样本是抽样 90 条，不是全量」。占比只作风向参考。

### 每条评论保存的字段

| 字段 | 含义 |
|---|---|
| `text` | 评论文字 |
| `digg` | 赞数（「1.2万」换算成 12000） |
| `replies` | 回复数 |
| `isAuthor` | 是不是作者 |
| `isReply` | 是不是楼中回复 |
| `stratum` | 抽样层：赞高／位置 |
| `pos` | 加载顺序里的位置 |
| `authorLiked` | 作者是否赞过 |
| `when` | 相对时间，例如「3天前」。只留时间，去掉 IP 属地 |

不保存昵称和 IP 属地。

## 五、失败处理

| 情况 | 记为 |
|---|---|
| 页面评论数 >500，却抓到 0 条 | **失败**，不是「0 条」。不写评论文件，下次重跑会重抓 |
| 页面打不开、超时 | 失败 |
| 页面打开了，但没有评论区 | 空（要人工判断） |
| 评论数 ≤500、年份不合格、只读数 | 跳过 |
| 前面已停下、资源占满 | 未访问 |

1. 采集员遇到失败就停，原样返回日志，不排查，不重试。
2. 批量运行时，单条失败不影响其他片子，最后在汇总表里标出。
3. 读不到评论数、或疑似被限制时，**立即停下整批**，剩下的写进汇总表的「未访问」。

### 产出

- 每条片子一个目录，里面有 `评论.json`。
- 输出目录下有 `采集汇总.tsv`：片子ID、状态、条数、原因。同一 ID 重跑，新结果覆盖旧行。
- 分析员先读 `采集汇总.tsv`，再决定「失败」「空」的片子要不要补采。
- 分析员不读 `评论.json` 原文，只读 `评论样本.tsv` 和 `评论分簇.md`。

## 六、交付格式

- 每条参考视频都带可点击链接：`https://www.douyin.com/video/<id>`。不交分享短链（会失效）。
- 作者名挂主页链接：`https://www.douyin.com/user/<sec_uid>`，从视频页的作者链接读取。取不到写「链接待补」。
- 作者、读数、时长、发布日、采集日同列。
- 所有读数带抓取时间。比率写出分子、分母和算式。

## 七、数据与隐私

1. 抓到的评论只用于你自己的分析。不要公开传播。
2. 评论文字会发给你使用的大模型服务。发送前已去掉昵称和 IP 属地。
3. 不要把他人的视频文件、逐字稿、截图、评论提交到公开仓库，或发到任何公开场合。
4. `save_media.py` 保存的文件，在转录和截关键帧都完成后默认删除，只留逐字稿和关键帧图。要保留时，命令加 `--keep-media`。你自己提供的文件，脚本不删。关键帧图也是他人的内容，只留在你自己的电脑上。
