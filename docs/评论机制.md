# 评论机制

本文件定义怎么分析评论区：观众被触发了什么（机制层），评论在评论区做了什么（评论动作），以及怎么从评论归纳到机制。选题验证和对标复原都用这一套。

## 一、两层

1. **机制层**（四格）：观众被片子触发了什么。这是结论，要从评论向上归纳。
2. **评论动作**（B0–B8）：一条评论在评论区做了什么。这是文本分类，可以直接数。
3. 同一个动作可以来自不同机制。不要把动作直接当机制用。

每条片子都要回答三件事：核心机制在哪一格？同时激活哪几格？触发点是哪一镜？

## 二、机制层：四格

| | 接纳 | 排斥 |
|---|---|---|
| **思辨**（判断对不对、能不能用） | **思辨·认同**：接受片子的主张，并往下想：补充、解释原因、追问办法、打算照做 | **思辨·不认同**：不接受片子的主张。分两档：存疑（「真的吗」「我做不到」），反对（「不对」「应该是另一种」） |
| **感受**（体会处境、认出自己） | **感受·共情**：体会人物的处境或情绪，或认出自己。包括心疼、后怕、感动、会心一笑 | **感受·反感**：排斥人物言行或片子的表达。包括厌恶、愤怒、被冒犯、被指责 |

### 判法

1. **看观众被触发了什么，不看片子内容的类型。** 评论在判断、解释原因、追问办法、补充做法 → 思辨。评论在体会处境、认出自己、心疼、后怕、骂人物 → 感受。内容类型（观点、知识、办法；场景、言行、遭遇）另记一列，只作参考。
2. **方向的对象分开定。** 思辨的对象是片子在这一点上的主张。感受的对象是评论点名的人物：心疼甲 → 共情；骂乙 → 反感。对象在片外时（例如骂现实中的某类人）照样记，并注明「对象在片外」。
3. **「害怕」看对象。** 替片中人物后怕、想到自己身边的人 → 共情。觉得片子吓人、说片子「制造焦虑」 → 反感。
4. **夸整条片子。** 夸准、夸有用 → 思辨·认同。夸感人 → 感受·共情。
5. **片外。** 高赞簇在片里找不到触发点，记「片外」，不进四格，单独报占比。片外 ≥30% 时，结论标「可信度低」。
6. **无法判定。** 纯 @、纯表情、无关评论，记「无法判定」，不进四格。

### 组合：一条片子同时激活几格

| 组合 | 同时激活 | 判据 | 例 |
|---|---|---|---|
| 争议 | 思辨·认同 ＋ 思辨·不认同 | 针对片子的**同一个主张**，两边各 ≥15%。两拨人都反对片子（理由不同）是一边倒的不认同，不是争议 | 片子说某种做法对，评论一半赞同、一半反对 |
| 替人不平 | 感受·共情（吃亏一方）＋ 感受·反感（占便宜一方） | 一边心疼一个人，一边骂另一个人，两边各 ≥15% | 一方隐瞒事故，评论心疼受害者、骂隐瞒者 |
| 被说中 | 思辨·不认同 ＋ 感受·反感（被指责） | 评论在辩解「我为什么这样做」，带火气 | 片子批评一种常见做法，评论区大量人解释自己为什么也这样做 |
| 知识缺口 | 感受·共情 ＋ 思辨·认同（追问办法） | 情境让人后怕，片子没给办法，观众追问 | 演示一种危险情境但没讲怎么脱困，评论区大量追问 |

## 三、评论动作：B0–B8

每条评论记一个主码，只看它在评论区做了什么。

| 码 | 动作 | 判法 | 例 |
|---|---|---|---|
| B1 | 表态 | 评价对错、站队、下判词、给结论 | 「第一种做法才对」 |
| B2 | 讲自己 | 讲自己或家人的经历、原话、行为 | 「我也遇到过，当时……」 |
| B3 | 给信息 | 补充知识、给办法、解释原因、纠正事实 | 「这是因为……」「按一下这个键就行」 |
| B4 | 提问 | 追问、求助、反问 | 「那这种情况怎么办？」 |
| B5 | 招呼人 | @某人，或 @ 加「看看」「注意」或一句情绪短语 | 「@小王 看看」 |
| B6 | 对创作者说 | 致谢、夸、催更、骂片子或作者 | 「感谢科普」 |
| B7 | 抒发 | 只有感叹或情绪，没有观点、经历、信息 | 「太可怕了」 |
| B8 | 玩 | 玩梗、复读片中台词、只为逗乐 | 复读片中一句台词 |
| B0 | 其他 | 单个表情、「1」、看不懂、无关 | 「[赞]」 |

### 编码规则

1. 一条评论只记一个主码。拿不准也要选一个，可加备注「疑」。
2. 一条评论做了两件事，主码记「删掉它，这条评论就不成立」的那件。
3. 按功能编码，不按语气。调侃里有判断 → B1；有原因或办法 → B3；只为逗乐 → B8。
4. 只复述人物台词：复读片中台词 → B8；讲自己身边人说过的话 → B2；看不出 → B2。
5. @ 后面有完整提醒或办法 → B3；@ 加评价 → B1；只有 @ 或 @ 加短话 → B5。
6. 回复别人的评论，照样按它做的事编码。
7. 问句不是真在问、只想找人认同 → B4，备注「修辞问」。
8. 站队加经历：经历是站队的理由 → B1；经历是主体 → B2。
9. 作者的评论和回复不编码，不进样本。
10. B0 超过 10%，说明分类有漏，要回查。

### 机制和动作的常见搭配

搭配不互斥，只作参考。

| 机制格 | 常见动作 |
|---|---|
| 思辨·认同 | B3 补充或解释、B4 追问、B1 赞同、B6 致谢 |
| 思辨·不认同 | B1 反对、B4 反问、B3 纠错、B2「我做不到」 |
| 感受·共情 | B2 认领、B5 @身边人、B7 抒发 |
| 感受·反感 | B1 判词或辩护、B6 骂片子、B7 抒发 |

## 四、从评论归纳到机制：六步

簇不用固定词典。每个评论区按它自己的内容，由大模型现场分簇。占比一律由脚本算，大模型不心算。

| 步 | 谁做 | 产物 |
|---|---|---|
| 1 取样本 | 脚本 | `评论样本.tsv`、`评论底盘.md` |
| 2 定簇与逐条标注 | 大模型 | `评论标签.json` |
| 3 加总与检验 | 脚本 | `评论分簇.md` |
| 4 找触发点、定格 | 大模型 | 在 `评论标签.json` 的簇上补「格」「触发点」 |
| 5 加总四格 | 脚本（重跑第 3 步） | `评论分簇.md` 的「四格加总」 |
| 6 一句结论 | 大模型 | 评论触发表下的结论 |

1. **取样本。** 用采集时的抽样（见 [采集规则](采集规则.md)），去掉作者评论。运行 `python scripts/comment_cluster.py sample <评论.json>`。同题多条片子合成一个池子：一次传入多个 json，加 `--out <目录>`。
2. **定簇与逐条标注。** 先通读样本全部行，再定簇，最后逐条标注。定簇规则：
   1. 按评论在说什么分簇：话题、对象或事件。不按语气分，不按关键词分。
   2. 簇名用评论里的原词或原事，例如「三年只发一盒月饼」。不用抽象标签，不用编号。
   3. 每簇写一句「定义」，再写「含」「不含」各一条，划清和相邻簇的边界。
   4. 簇数 4–8 个。小簇合并进「其他」。纯表情、纯 @、看不懂的记「无法判定」。
   5. 一条评论只标一个主簇和一个 B 码。
   6. 不预设簇。别的片子用过的簇名，只有在这个评论区确实存在时才用。
3. **加总与检验。** 运行 `comment_cluster.py summarize <目录>`。脚本算各簇条数、赞、占比、主要动作、B 码分布，并标出大簇（占样本赞 ≥5%，或条数前 5）。「其他」占赞 >15% 时，退回第 2 步重分。
   - **复核**：另起一个 agent，只给它簇定义和 `评论底盘.md` 里列出的 10 个复核序号，让它独立标注，写成另一份标签文件。运行 `comment_cluster.py recheck <目录> <复核标签.json>`。簇或 B 码一致率 <80% 时，先改簇定义，再重标。
4. **找触发点、定格。** 每个大簇回到片里，写出它回应哪一镜、哪一句；找不到记「片外」。再按第二节判法定层面和方向。把「格」「触发点」写回标签文件对应的簇。
5. **加总四格。** 重跑 `summarize --force`。脚本把簇的赞加到四格（片外、无法判定、其他不进），按赞、按条数各算四格内的占比。最大的格是**核心机制**；其余 ≥15% 的是**同时激活**。最高赞一条占样本赞 ≥30% 时，脚本并列去掉它的结果；两次核心不同，两个都报。再对照组合表。
6. **一句结论。** 写清：核心机制在哪一格，触发点是哪一镜，同时激活哪几格，哪几格没被激活。

### 评论触发表

复原卡和报告都用这张表。每个大簇一行。

| 簇 | 代表句（赞） | 占样本赞 | 触发点（镜次＋原句） | 触发内容类型 | 机制格 | 主要动作 | 激发人群 | 证据等级 |
|---|---|---|---|---|---|---|---|---|

- **代表句**：每簇最多 2 句，只显示前 10–15 字，后面用「……」隐藏，带赞数。完整原句只留在 `评论分簇.md`。
- **激发人群**：这簇评论是谁写的。链条是：内容 → 机制格 → 人群 → 评论动作。
- **证据等级**：🟢 评论复述了片中原句；🟡 按语义推断；🔴 只凭簇名推断。
- 表下写：四格占比（按赞、按条数）、片外占比、核心机制、同时激活、组合、前三大簇的触发点是同一处还是分散在不同段、一句结论。
- 这张表是评论归因的唯一出处。复原卡的归因表不再写评论。

## 五、在选题验证里怎么用

对标片和同题片都做第四节的归纳，回答三件事：

1. **机制属于谁。** 几条同题片的核心格一致，说明机制属于选题本身；不一致，说明机制属于某条片子的做法。
2. **能不能复制。** 触发点是选题自带的（情境本身就让人想说话），还是靠某一镜的做法（例如片子故意没给办法）。
3. **还有什么空间。** 有没有没激活、但选题有条件激活的格。
