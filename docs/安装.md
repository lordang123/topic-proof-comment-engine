# 安装

先给结论：运行一个安装脚本，再自己做两件 agent 做不了的事（装 ego lite、扫码登录抖音）。全程约 20–40 分钟，大部分时间在下载 3 GB 的转录模型。

## 一、你需要什么

| 项 | 要求 |
|---|---|
| 电脑 | macOS（Apple 芯片最好），或 Windows 10/11 |
| 硬盘 | 空闲 6 GB 以上（模型约 3 GB，Python 依赖约 1–3 GB） |
| 网络 | 能访问 Hugging Face，或它的镜像 hf-mirror.com（脚本会自动换） |
| AI agent | Claude Code 或 Codex，二选一 |
| 抖音账号 | 用来在 ego lite 里登录 |

**转录速度：**

| 电脑 | 引擎 | 1 分钟视频大约要 |
|---|---|---|
| Apple 芯片 Mac | mlx-whisper（GPU） | 10–30 秒 |
| Windows，有 NVIDIA 显卡 | faster-whisper（CUDA） | 10–40 秒 |
| Windows，没有 NVIDIA 显卡 | faster-whisper（CPU） | 几分钟。慢时改用小模型：`--model medium` 或 `--model small` |
| Intel 芯片 Mac | faster-whisper（CPU） | 同上 |

- Apple 芯片 Mac 一行已实测：60 秒视频转录用时 14 秒（不含第一次加载模型）。其他三行是参考值，还没有实测。

## 二、运行安装脚本

脚本会安装 Python（没有时）、ffmpeg、Python 依赖，下载转录模型，最后自检。可以重复运行，下载中断后重跑会续传。

### macOS

1. 没有 Homebrew 时，先按 <https://brew.sh> 安装。
2. 打开「终端」，进入本仓库目录，运行：

```bash
bash install.sh
```

### Windows

> Windows 安装脚本还没有在真机上测过。遇到问题，请把报错原文提交到仓库的 Issues。

1. 打开本仓库文件夹，点一下窗口上方的地址栏，输入 `powershell`，按回车。
2. 粘贴下面这行，按回车：

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force; .\install.ps1
```

- 脚本用 winget 装 Python 3.12 和 ffmpeg。没有 winget 时，先在 Microsoft Store 安装「应用安装程序」。
- 检测到 NVIDIA 显卡时，自动装 CUDA 运行库（约 1 GB），不需要另装 CUDA Toolkit。显卡驱动要你自己装：<https://www.nvidia.cn/drivers/>。

### 交给 agent 装

也可以在仓库目录里打开 Claude Code 或 Codex，说：「按 docs/安装.md 帮我安装并自检」。agent 会运行上面的脚本。

- Windows 上用 Codex 时，建议你自己在普通 PowerShell 里运行安装脚本。Codex 的沙盒会挡住 winget（它在系统的 WindowsApps 目录里），安装会中途停下。

## 三、安装 ego lite 并登录抖音（只能你自己做）

本项目用 ego lite 浏览器，在你自己的登录状态下读取抖音页面。它是第三方软件，本仓库不附带。

1. 到 ego lite 官网 <https://lite.ego.app/> 下载安装（macOS 或 Windows 版）。
2. 打开 ego lite，完成首次引导。引导会注册 `ego-browser` 命令。
3. 在 ego lite 里打开 <https://www.douyin.com>，扫码登录。
4. 重新打开终端，运行自检，确认 `ego-browser 命令` 一项是 OK：

| 系统 | 命令 |
|---|---|
| macOS | `.venv/bin/python scripts/check_env.py` |
| Windows | `.venv\Scripts\python.exe scripts\check_env.py` |

提示找不到 `ego-browser` 时：macOS 把 `~/.local/bin` 加进 PATH；Windows 重开 PowerShell。

## 四、Codex 的权限设置

选题验证要做两件事：访问网络，调用本机的 ego lite。Codex 默认的沙盒会挡住它们，表现是做一步就停下来问你。Claude Code 没有这个问题，可以跳过本节。

1. 仓库里的 `.codex/config.toml` 已经设好：只在本仓库目录内允许写入和联网，越界操作仍会问你。第一次在本仓库打开 Codex 时，选择信任这个目录，这份设置才会生效。
2. 仍然连不上 ego lite（报「无法连接」或子进程提前退出）时，在 Codex 里输入 `/approvals`，选「Full access」。只在本仓库里这样做。
3. Windows：Codex 不要在 WSL 里运行。WSL 是 Linux，连不到 Windows 上的 ego lite。

## 五、开始使用

在仓库目录里打开 Claude Code 或 Codex，说：

> 验证这条：https://www.douyin.com/video/<视频id>

- 分享短链（`v.douyin.com/...`）要先在浏览器打开，复制地址栏里的完整地址。
- 运行时 ego lite 要开着，不要关。脚本一次只开一个抖音页面，页面之间会等 8–40 秒，这是故意的。
- 你可以随时在 ego lite 里点「接管」。脚本会停下，不动你的页面。

## 六、配置

要改默认值，把 `config.example.json` 复制成 `config.json` 再改。`config.json` 不会提交到仓库。

| 项 | 默认 | 含义 |
|---|---|---|
| `work_dir` | `work` | 产物目录 |
| `comment_min` | 500 | 有效同题片的单条评论数下限（大于它才算） |
| `years_back` | 1 | 只认当年和前 N 年发布的片子 |
| `like_min` | 1500 | 推荐和搜索卡片的点赞预筛线，低于它不打开 |
| `max_top` / `hot_k` / `pos_m` | 200 / 45 / 45 | 评论加载上限、按赞取几条、按位置取几条 |
| `reply_top` | 3 | 展开回复的评论条数 |
| `whisper_model` | `large-v3` | 转录模型。CPU 慢时改 `medium` 或 `small` |
| `hf_endpoint` | 空 | 模型下载源。空＝先连 Hugging Face，失败再用 hf-mirror.com |
| `board_title` / `board_subtitle` | 格厚AI · 爆款内容工厂 / GEHOU · NEURAL CONTENT ENGINE | 结果页和光球看板左上角 logo 旁的品牌名和标语 |

访问间隔不在配置里，也不要改小。见 [采集规则](采集规则.md) 第三节。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 模型下载很慢或失败 | 重跑安装脚本会续传。仍失败时，在 `config.json` 里设 `"hf_endpoint": "https://hf-mirror.com"` |
| Windows 报缺 `cublas64_12.dll` 或 `cudnn` | 运行 `.venv\Scripts\python.exe -m pip install -r requirements-gpu.txt`；仍不行时更新显卡驱动。脚本会自动退回 CPU |
| Windows 终端里中文是乱码 | 用 PowerShell 运行；脚本已强制 UTF-8 输出。仍乱码时先运行 `chcp 65001` |
| 脚本退出码 3、提示「疑似受限」 | 停下，过一段时间再试。不要缩短间隔 |
| 脚本退出码 76 | 你在运行中接管了浏览器。重跑同一条命令即可 |
| agent 做一步就停下来问 | Codex 的沙盒挡住了联网或 ego lite。见第四节。另外，对 agent 说「按 .agents/skills/选题验证/SKILL.md 一次跑完」 |
| 保存视频失败 | 加密流、图文作品、私密作品不支持，脚本不做绕过。请自己提供视频文件，交给 agent 直接转录 |
| 保存的视频不见了 | 转录和截关键帧都完成后默认删除。要保留时，`frames.py`（只取音轨时为 `transcribe.py`）加 `--keep-media` |
| 看板是空的、只有引导 | 还没有选题，或改完报告后没刷新。运行 `scripts/board_data.py`，再刷新页面。想看效果用 `board/index.html?demo=1` |
| `采集汇总.tsv` 里有「失败」 | 不是 0 条评论，是没抓到。可以重跑同一条 `collect.py read` 命令补采 |
