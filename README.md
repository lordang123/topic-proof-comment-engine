# topic-proof-comment-engine

给一条抖音视频，判断它的选题是偶然的孤立爆款，还是能复现的选题；再找出他的评论由视频哪一段、通过什么机制触发。

> **使用前先读这五条：**
>
> 1. 本项目只供个人学习和研究。
> 2. 只保存你有权观看的内容。首选你自己已有的视频文件。
> 3. 保存的视频在截完关键帧后默认删除，只留逐字稿和关键帧图。
> 4. 账号被限流、限制或封禁的风险，由你自己承担。
> 5. 本项目与抖音、字节跳动没有任何关联。
>
> 完整内容见[风险与免责声明](#风险与免责声明)。使用本项目，即表示你已阅读并接受该声明。

## 能做什么

| 问题                | 回答方式                                   |
| ----------------- | -------------------------------------- |
| 这个选题被验证过吗？        | 找同一选题的其他爆款，逐条核评论数和发布年份，判定 A／B／C／D 四种情形 |
| 有没有流量更高的同题片？      | 同题片评论数 ≥ 对标的 2 倍，列出链接和倍数               |
| 评论区在聊什么？          | 大模型按这条评论区自己的内容分簇；脚本算各簇占比               |
| 评论由视频哪一段触发？靠什么机制？ | 对标复原：把每个大簇对到镜次和原句，定机制格（四格）             |
| 值不值得做这个选题？        | 报告给出「做／不做」建议、依据和最大的未知项                 |

# 不做什么

* 不给改编方案，不写台词。

* 不保证结果。结论是判断的依据，不是流量承诺。

* 不保存评论者昵称和 IP 属地。

## 流程

```
你的输入：视频链接，加上视频文件（首选）
  │
  1 转录：用你给的视频文件，本地语音识别，出逐字稿。
    没有文件时可选：保存当前视频用于学习研究（取音轨和画面，截完关键帧后默认删除，只留逐字稿和关键帧图）
  2 读对标页面：读数（赞、评、藏、转、发布日）＋抽样评论
  3 找同题片：按逐字稿写选题卡、定搜索词；读推荐视频，再搜索（必做）；逐条核评论数和年份
  4 评论分簇：脚本出样本 → 大模型定簇、逐条标注 → 脚本算占比
  5 对标复原：按片中转折切段，截关键帧（开头 3 秒、转折、切镜、结尾），把大簇对到镜次，定机制格
  6 出报告：情形判定、同题表、评论机制结论、做不做
  7 看结果：每个选题一张 4 屏结果页；所有选题汇总在光球看板
```

## 安装

完整步骤见 [docs/安装.md](docs/安装.md)。支持 macOS（已实测）和 Windows 10/11（**未经实测**，欢迎反馈问题）；Claude Code 和 Codex 都能用。

| 系统                       | 命令                                                                |
| ------------------------ | ----------------------------------------------------------------- |
| macOS                    | `bash install.sh`                                                 |
| Windows（PowerShell，未经实测） | `Set-ExecutionPolicy -Scope Process Bypass -Force; .\install.ps1` |

脚本装好 Python、ffmpeg、依赖和转录模型（约 3 GB），最后自检。之后你自己做两件事：

1. 安装 ego lite 浏览器，完成首次引导。
2. 在 ego lite 里打开抖音，扫码登录。

然后在仓库目录里打开 agent，说：「验证这条：<抖音视频链接>」。

## 脚本

| 脚本                           | 做什么                                                                         |
| ---------------------------- | --------------------------------------------------------------------------- |
| `scripts/save_media.py`      | 可选。保存当前视频用于学习研究：在你登录的浏览器页面里，取回播放器已经在播的文件。默认取音轨和画面（`--audio-only` 只取音轨），一次一条 |
| `scripts/transcribe.py`      | 本地语音识别：Apple 芯片 Mac 用 mlx-whisper，其他电脑用 faster-whisper                      |
| `scripts/frames.py`          | 截关键帧：开头 3 秒、你定的转折点、自动找到的切镜、结尾。截完删除 `save_media.py` 保存的文件                    |
| `scripts/collect.py`         | 读推荐视频、搜索、逐条读视频页和抽样评论                                                        |
| `scripts/comment_cluster.py` | 评论取样本、加总占比、复核一致率                                                            |
| `scripts/ego_run.py`         | 所有浏览器脚本的唯一入口：全机排队，一次一个页面，用完就收                                               |
| `scripts/result_page.py`     | 把一个选题做成 4 屏结果页（结论、同题对比、评论机制、对标结构与关键帧），1920×1080，适合录屏                   |
| `scripts/board_data.py`      | 刷新光球看板：扫描 `work/`，重建各选题的结果页，写 `board/data.js`                                      |
| `scripts/check_topic.py`     | 交付前检查一个选题的各步是否做完；缺什么、回哪一步、跑什么命令（给 agent 用） |
| `scripts/check_env.py`       | 自检，列出缺什么、怎么修                                                                |

## 结果页与光球看板

两个页面都在浏览器里直接打开，不联网，不需要开服务。页面只显示 `work/` 里已有的结果，所有占比都抄自脚本输出，页面自己不算。

| 页面 | 怎么得到 | 显示什么 |
|---|---|---|
| 结果页 `work/<选题>/选题验证结果页.html` | `python scripts/result_page.py work/<选题>` | 4 屏：① 情形与建议 ② 同题片评论数对比 ③ 评论簇与四格 ④ 框架线与关键帧。键盘 ↓/↑ 翻屏，`?static=1` 关动画 |
| 光球看板 `board/index.html` | `python scripts/board_data.py` | 中心光球＝已验证选题数；5 个模块：选题验证、同题爆款、评论机制、对标复原、AI 员工。点模块展开，点条目看详情；T 键自动导览 |

- **刚装好、还没有数据**：看板显示引导，告诉你第一步做什么。没有数据的位置显示「—」。
- **想先看效果**：打开 `board/index.html?demo=1`。这是编的示例数据，页面上一直有「示例数据，非真实账号」水印。
- **我的账号（可选）**：把 `my_account.example.json` 复制成 `my_account.json`，自己填作品和读数，再运行 `board_data.py`，看板多出「我的账号」模块。不填就没有这个模块。本项目不自动读取你的账号后台。
- `board/data.js` 和 `my_account.json` 只在你的电脑上，不进仓库。
